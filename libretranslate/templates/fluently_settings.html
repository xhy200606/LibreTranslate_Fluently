尚未探测

网页匿名接口不是官方承诺的长期公共 API，可能遇到限流、访问验证或协议变更。免费额度与供应商政策各自独立；连接测试只发送固定示例句。

其他 AI 翻译服务

默认使用 B站 Index-Translate 免费模型；也可在这里添加 OpenAI 兼容接口。首页始终只选一个引擎。

API Key 只传送给本机服务端并保存于持久卷；保存后的真实 Key 不会返回浏览器。填写新 Key 才会替换旧值；留空保持不变。

提示词与推理

按 FluentRead 的服务独立配置思路，统一定制 AI 翻译和深度讲解。

服务端运行配置

覆盖 LibreTranslate 的全部已登记 LT_ 参数。修改后重启容器才会生效；少数网络/安全参数仍需要在部署时提供环境变量。

为了不丢失访问权限：DISABLE_WEB_UI 等危险设置也可在 GUI 配置，但更改前请确认恢复方案。HOST / PORT 等启动参数须重启，并同步 Docker 端口映射。
