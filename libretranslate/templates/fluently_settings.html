数据源与分流权重

权重根据供应商响应速度、成功率和冷却状态变化。0% 表示当前不会被选中；实际流量请参考已发送次数。

网页匿名接口不是官方承诺的长期公共 API，可能遇到限流、访问验证或协议变更。免费额度与供应商政策各自独立；连接测试只发送固定示例句。

官方机器翻译 API

独立于匿名免费网页协议。DeepL、百度、有道、腾讯云、Google Cloud、Azure、阿里云、小牛及自建 DeepLX；使用你自己的密钥和额度。

密钥只写入 Docker 持久卷，页面不显示已保存的原文。测试连接会发送示例文本，可能产生额度费用。未完整配置的服务不会出现在首页引擎列表。DeepLX 只接受可信 HTTPS 或本地服务地址。

AI 服务预设

常见 OpenAI 兼容服务，以及 Claude Messages、Gemini generateContent、Azure OpenAI。选择模板后填写密钥与有效模型 ID。

API Key 只传送给本机服务端并保存于持久卷；保存后的真实 Key 不会返回浏览器。填写新 Key 才会替换旧值；留空保持不变。

服务端运行配置

覆盖 LibreTranslate 的全部已登记 LT_ 参数。修改后重启容器才会生效；少数网络/安全参数仍需要在部署时提供环境变量。

为了不丢失访问权限：DISABLE_WEB_UI 等危险设置也可在 GUI 配置，但更改前请确认恢复方案。HOST / PORT 等启动参数须重启，并同步 Docker 端口映射。
